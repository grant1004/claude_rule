# 專案初始化

目的：讓每個專案都有一份欄位相同的 CLAUDE.md，核心規則才能在每個專案用同樣的方式找到指令和驗證方法。

1. 讀範本 `~/.claude/claude_rule/templates/CLAUDE.template.md`（Windows 是 `%USERPROFILE%\.claude\claude_rule\templates\CLAUDE.template.md`）。
2. 從專案本身找答案，不要猜：建置系統與方案檔、測試專案與測試框架、既有的 README 與 CI 設定、目錄結構。
3. 指令要實際跑過一次再寫進去，並記下耗時：建置、單一測試、全套測試。這些指令派背景子代理去跑並計時，主對話不在前景等。跑不起來就照實寫「未驗證」和錯誤訊息，不要填看起來合理的指令。
4. 依範本的欄位填寫。欄位名稱和順序不要改；沒有內容的段落整段刪掉。「架構重點」只寫讀程式碼不容易看出來的事。
5. 「不能動的契約」「只能實機或人工驗證的項目」「Git」這三段從程式碼看不出來。列出你的推測並標明是推測，由我確認或補充。
6. 把草稿給我看，我確認後才寫入專案根目錄的 `CLAUDE.md`。專案已經有 CLAUDE.md 時不要覆蓋：列出它和範本欄位的差異，問我要不要調整。
7. 完成後回報：哪些欄位已驗證、哪些是推測、哪些還空著。
